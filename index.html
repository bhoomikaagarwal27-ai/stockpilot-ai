Reorder suggestions rule-based calculation — AI only explains it

Formula (transparent, so a planner can sanity-check it):
Avg daily use = mean of last 30 days' issues · Reorder point (ROP) = avg daily use × (lead time + safety days) · Max level = ROP + 20 days of use
Suggested qty = Max level − current stock, rounded up to the vendor MOQ. For finished goods the action is a production plan, not a purchase order.

AI connection

The assistant uses Google Gemini. Choose one: (1) an Apps Script proxy URL that keeps the key on the server (recommended for a public link), or (2) your own Gemini API key, saved only in this browser. With neither, the app runs on its built-in rule engine.



Data & privacy

• All data is fictional and generated in the browser.
• When AI is on, your chat message plus a compact stock table (item, stock, usage, lead time, status) is sent to Google's Gemini API. Nothing else is sent; no personal data is collected.
• Chat history, entries and settings are saved in this browser (localStorage) so a refresh doesn't lose work.
• Reorder quantities are calculated by fixed rules, not by the AI. The AI explains and answers questions; a human approves every order.
