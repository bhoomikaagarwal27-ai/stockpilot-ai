Chart audit

Every chart the data allows is generated and checked; only approved charts are shown on the dashboard. Rules: approved chart type · enough groups / points · ≥ 50% data coverage · valid calculation (no adding days, rates or IDs) · same units · values must vary · pattern strength for scatter, Pareto, clustered and histogram charts · decision relevance.

Click a row for its usage trend. CRITICAL = will run out before a new lot can arrive (cover < lead time) or stock is zero · LOW = below reorder point · EXCESS = above max level or no use in the period · NO USAGE DATA = no movements, average use or min level in the file.

Reorder suggestions rule-based calculation — AI only explains it

Formula (shown so a planner can check it): Sales velocity = 50% × last-7-day average + 50% × 30-day average of issues/sales (or the file's average-use column) · These settings are saved with each dataset · Order by = date stock would run out − supplier lead time · Reorder point (ROP) = the file's Min/Reorder level if given, else avg daily use × (lead time + safety days) · Max level = the file's Max level, else ROP + order-cycle days of use · Suggested qty = Max − current stock, rounded up to MOQ.

Your data & privacy

• Your file is read inside your browser. It is not uploaded to any server or to GitHub.
• Data, entries and chat are saved in this browser (localStorage) so a refresh keeps them. Use “Clear all data” on shared computers.
• When AI is used, only your question and a compact table of relevant items (name, stock, use, lead time, status, suggested qty) are sent to Google Gemini.
• Reorder quantities are calculated by fixed rules, not by AI. A human approves every order.
